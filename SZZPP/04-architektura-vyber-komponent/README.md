## 4 — Architektura počítačů: výběr komponent

- [Zadání okruhu (PDF)](../ZadaniOkruhu/PCA-I.pdf)

### Požadované znalosti a dovednosti

- principy fungování počítače a jeho komponent (procesor, základní deska, RAM, GPU, úložiště, zdroj)
- kompatibilita komponent a jejich výběr dle rozpočtu a požadavků
- principy instalace operačního systému a ovladačů
- nastavení BIOSu a optimalizace výkonu
- práce s periferními zařízeními

### Charakteristika zkušební úlohy

Zadán rozpočet a požadavky na funkčnost počítače. Vybrat komponenty, **zdůvodnit volbu**, popsat sestavení, instalaci OS a ovladačů, nastavení BIOSu.

### Postup u zkoušky (60 min přípravy)

1. Vyjít z požadavků — na co počítač bude (kancelář / hry / práce s daty).
2. Určit, kde je úzké hrdlo, a tam dát peníze.
3. Projít kompatibilitu: socket CPU ↔ deska, typ a rychlost RAM, formát desky ↔ skříň, výkon zdroje, délka GPU.
4. Rozpočet rozepsat po položkách a ukázat, že sedí.
5. Zdůvodnit každou volbu jednou větou — tohle je nejdůležitější část.

### Co si nacvičit

- [ ] Vyřešit ukázkovou úlohu z PDF (kancelářský počítač za 15 000 Kč) se zdůvodněním
- [ ] Zopakovat aktuální sokety a generace CPU, typy RAM (DDR4/DDR5)
- [ ] Rozdíly SATA SSD / NVMe / HDD a kdy co
- [ ] Dimenzování zdroje a co znamená certifikace 80+
- [ ] Postup instalace OS a ovladačů, základní nastavení BIOSu (boot order, XMP/EXPO)
