# Otázka 1: Funkce a cykly

## Nejčastější chyby a jejich opravy

**Syntaktické:**
- chybějící `:` za `if/elif/else/for/while/def`
- špatné odsazení (mix mezer a tabů, nekonzistentní blok)
- nevyvážené závorky/uvozovky
- `return` mimo funkci

**Sémantické (nejzrádnější):**
- porovnávání **celého vstupu místo iterační proměnné** (`if text == "("` místo `if c == "("`) – klasická chyba z ukázky
- **while bez update proměnné** → nekonečná smyčka
- `range(a, b)` nezahrnuje `b` → off-by-one chyby
- `/` (float dělení) vs `//` (celočíselné) záměna
- **mutable default argument**: `def f(x, acc=[]):` – seznam se sdílí mezi voláními! Správně: `acc=None; if acc is None: acc = []`
- chybějící `return` → funkce vrátí `None` a chyba se projeví až o pár řádků dál
- `==` vs `is` (identita vs hodnota) – zvlášť u porovnání s `None` (má být `is None`)
- porovnání floatů přes `==` (zaokrouhlovací chyby) → radši `abs(a-b) < eps`
- záměna pozičních a pojmenovaných parametrů při volání (pořadí!)
- vyhození špatného typu výjimky nebo bez zprávy (`raise ValueError("popis")`)

## Kompletní opravený a rozšířený kód

```python
def test_of_parentheses(text: str, brackets: tuple[str, str] = ("(", ")")) -> bool:
    """
    Testuje, zda jsou závorky v textu správně uzávorkovány.
    brackets: dvojice (otevírací znak, uzavírací znak)
    """
    if not text:
        raise ValueError("Vstupní řetězec nesmí být prázdný.")

    open_ch, close_ch = brackets
    para_count = 0
    for c in text:
        if c == open_ch:
            para_count += 1
        elif c == close_ch:
            para_count -= 1
            if para_count < 0:
                return False
    return para_count == 0


def max_nesting_level(text: str, brackets: tuple[str, str] = ("(", ")")) -> int:
    """
    Vrací maximální úroveň zanoření závorek.
    Pokud text není správně uzávorkován, vyhazuje ValueError.
    """
    if not text:
        raise ValueError("Vstupní řetězec nesmí být prázdný.")

    open_ch, close_ch = brackets
    level = 0
    max_level = 0
    for c in text:
        if c == open_ch:
            level += 1
            max_level = max(max_level, level)
        elif c == close_ch:
            level -= 1
            if level < 0:
                raise ValueError("Závorky nejsou správně uzávorkovány.")
    if level != 0:
        raise ValueError("Závorky nejsou správně uzávorkovány.")
    return max_level
```

## Výsledky ladění – jak to popsat u zkoušky

| Vstup | `test_of_parentheses` | `max_nesting_level` | Poznámka |
|---|---|---|---|
| `"(())"` | `True` | `2` | funguje |
| `")(())("` | `False` | vyhodí `ValueError` | nevyvážené, level < 0 hned na začátku |
| `""` | vyhodí `ValueError` | vyhodí `ValueError` | ošetřený vstupní podmínkou |
| `"[a][b]"` s `brackets=("[","]")` | `True` | `1` | ukazuje funkčnost obecného parametru |

Vždy popiš: co jsi testoval, co se stalo, a **proč** (typicky: level klesl pod 0 → nevyvážené; level != 0 na konci → chybí uzavření).
