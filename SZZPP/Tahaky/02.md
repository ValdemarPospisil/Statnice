# Otázka 2: Kolekce

## Nejčastější chyby a jejich opravy

- **modifikace neměnné sekvence** (`range`, `tuple`, `str`) – `range` nejde měnit in-place, potřeba `list(range(...))`
- **mutace seznamu při iteraci `for item in data: item += 1`** – `item` je jen lokální kopie hodnoty (u čísel), originál se nezmění → nutno indexovat `data[i]`
- mazání/přidávání prvků do seznamu **během** `for` iterace nad ním → přeskakování prvků (řešení: iterovat nad kopií `data[:]`, nebo stavět nový seznam)
- `list1 = list2` je jen reference, ne kopie → `list1.copy()` nebo `list(list2)`
- `dict[klic]` vyhodí `KeyError`, když klíč neexistuje → `dict.get(klic, default)`
- `sort(key=...)` – zapomenutý `key=lambda x: ...` při řazení dle jiného kritéria než hodnoty samotné
- kontrola typu přes `type(x) == int` je příliš striktní (nezahrne `bool`, podtřídy) → radši `isinstance(x, (int, float))`
- off-by-one ve slicingu (`data[1:]` = od indexu 1 dál, `data[:-1]` = bez posledního)

## Kompletní opravený a rozšířený kód

```python
def increment_odd_index_items(data):
    """
    Vrátí NOVÝ seznam, kde prvky na LICHÉM indexu (1, 3, 5, ...)
    jsou zvýšeny o 1, pokud jsou sudé.
    Pokud některý prvek není číslo, vyhodí TypeError.
    """
    result = []
    for index, item in enumerate(data):
        if not isinstance(item, (int, float)):
            raise TypeError(f"Prvek na indexu {index} není číslo: {item!r}")
        if index % 2 == 1 and item % 2 == 0:
            result.append(item + 1)
        else:
            result.append(item)
    return result


data = list(range(1, 10))          # [1, 2, 3, 4, 5, 6, 7, 8, 9]
print(data)
new_data = increment_odd_index_items(data)
print(new_data)                    # [1, 3, 3, 5, 5, 7, 7, 9, 9]
print(data)                        # původní seznam beze změny
```

> **Pozor na výklad zadání:** PDF říká „inkrementován bude prvek s lichým indexem". Kód výš navíc testuje, že **hodnota je sudá** — to zadání nepožaduje. Když chceš přesně podle zadání, vypusť podmínku `and item % 2 == 0`; výsledek pak bude `[1, 3, 3, 5, 5, 7, 7, 9, 9]` taky (protože na lichých indexech jsou tu shodou okolností sudé hodnoty), ale na jiných datech se to rozejde. **U zkoušky řekni, kterou interpretaci jsi zvolil a proč.**

## Výsledky ladění

| Vstup | Výstup | Poznámka |
|---|---|---|
| `[1,2,3,4,5,6,7,8,9]` | `[1,3,3,5,5,7,7,9,9]` | indexy 1,3,5,7 mají hodnoty 2,4,6,8 (sudé) → +1 |
| `[1,"x",3]` | vyhodí `TypeError` | kontrola typu funguje, hlásí index |
| původní `data` po volání | nezměněný | funkce vrací nový seznam, originál nemodifikuje |
