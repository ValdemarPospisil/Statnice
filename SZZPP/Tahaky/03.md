# Otázka 3: Základy OOP

## Nejčastější chyby a jejich opravy

- **chybějící `self`** v definici metod (`def __init__(color):` → `def __init__(self, color):`)
- **chybějící `self.` při přístupu k atributu/metodě** (`return self.color`, `self.next_color()`)
- přístup ke class-level atributu bez prefixu (`colors[...]` → `self.__class__.colors[...]` nebo `Semaphore.colors[...]`)
- `__str__`/`__repr__` bez parametru `self`
- žádná validace v konstruktoru (nekontroluje se, zda je barva platná)
- index přetečení při `colors.index(color)+1` (poslední barva nemá následníka → `% len(colors)`)
- chybí `__eq__` → výchozí porovnání je přes identitu objektu, ne hodnotu
- chybí iterátor (`__iter__`/`__next__`) pro sekvenční přepínání

## Kompletní opravený a rozšířený kód

```python
class Semaphore:
    _colors = ["red", "yellow", "green"]

    def __init__(self, color: str):
        if color not in self._colors:
            raise ValueError(f"Neplatná barva: {color}")
        self.color = color
        self._index = self._colors.index(color)

    def __str__(self) -> str:
        return self.color

    def __repr__(self) -> str:
        return f"Semaphore({self.color!r})"

    def __eq__(self, other) -> bool:
        if not isinstance(other, Semaphore):
            return NotImplemented
        return self.color == other.color

    def __contains__(self, item) -> bool:
        """Umožní zápis `"red" in semaphore` – kontrola platné barvy."""
        return item in self._colors

    @property
    def stop(self) -> bool:
        """True, pokud se na této barvě má zastavit."""
        return self.color == "red"

    def next_color(self) -> "Semaphore":
        next_index = (self._index + 1) % len(self._colors)
        return Semaphore(self._colors[next_index])

    def __hash__(self) -> int:
        # NUTNÉ: definice __eq__ vypne dědičný __hash__ a objekt by nešel
        # vložit do množiny ani použít jako klíč slovníku.
        return hash(self.color)

    def __iter__(self):
        # Generátor = každá iterace má vlastní stav, vrací NOVÉ objekty.
        aktualni = self
        while True:
            yield aktualni
            aktualni = aktualni.next_color()
```

> **Proč generátor a ne `__next__` vracející `self`:** varianta, která mění `self` a vrací `self`, dá do seznamu **tentýž objekt vícekrát** — `list(itertools.islice(s, 3))` vrátí `[Semaphore('red'), Semaphore('red'), Semaphore('red')]`, protože všechny tři prvky ukazují na stejnou instanci. Generátor vrací pokaždé nový objekt a nemodifikuje původní semafor.

## Výsledky ladění

| Test | Výsledek | Poznámka |
|---|---|---|
| `Semaphore("blue")` | vyhodí `ValueError` | validace v konstruktoru |
| `Semaphore("red") == Semaphore("red")` | `True` | díky `__eq__` |
| `s = Semaphore("green"); s.next_color()` | `Semaphore('red')` | index přetekl přes `% len(...)` |
| `s.stop` | `True`/`False` | property, ne metoda (bez závorek) |
| `"red" in Semaphore("green")` | `True` | díky `__contains__` |
| `{Semaphore("red")}` | vloží se do množiny | díky `__hash__`; bez něj `TypeError: unhashable` |
| `list(itertools.islice(s, 4))` | 4 **různé** objekty | generátor, ne `self` |
