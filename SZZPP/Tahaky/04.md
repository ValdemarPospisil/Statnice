# Otázka 4: Výběr komponent podle účelu

## Tabulka: účel → priority komponent → důvod

| Účel použití | CPU | GPU | RAM | Úložiště | Poznámka/důvod |
|---|---|---|---|---|---|
| Kancelář, web, video | nižší střední třída (4 jádra stačí) | integrovaná (iGPU) | 8–16 GB | SSD (NVMe) 256–500 GB | úlohy nejsou CPU/GPU náročné, hlavní přínos SSD = rychlost startu OS a appek |
| Hraní her | střední/vyšší třída, dobrý single-core výkon | dedikovaná, hlavní položka rozpočtu | 16 GB | NVMe SSD 500GB+ | hry škálují hlavně s GPU, CPU nesmí GPU "bottleneckovat" |
| Střih videa/grafika | vyšší třída, více jader | dedikovaná se silnou VRAM | 32 GB+ | NVMe SSD (rychlé čtení/zápis velkých souborů) | rendering využívá multi-core i GPU akceleraci (encodery) |
| Vývoj/kompilace, VM | více jader/vláken | nemusí být silná | 32 GB+ | NVMe SSD | kompilace a VM jsou paměťově a vláknově náročné |
| Workstation/AI/ML | vysoký počet jader | GPU s velkou VRAM (klíčové) | 64 GB+ | rychlé NVMe, případně RAID | VRAM často limitující faktor pro modely |

## Obecné principy (zdůvodnění)
- **Vyváženost CPU/GPU** – nekombinovat drahou GPU se slabým CPU (bottleneck) a naopak.
- **RAM**: dnešní minimum 8 GB, standard 16 GB, tvorba obsahu/více VM 32 GB+; rychlost/frekvence RAM méně kritická než kapacita pro běžné použití.
- **Úložiště**: SSD (NVMe) vs HDD – SSD má řádově vyšší rychlost náhodného čtení/zápisu (žádné mechanické hlavy), HDD levnější na GB → kombinace SSD (systém+appky) + HDD (archiv) u nižšího rozpočtu.
- **Zdroj (PSU)**: dimenzovat s rezervou ~20–30 % nad špičkovým odběrem, certifikace 80+ (Bronze/Gold) = efektivita přeměny AC/DC.
- **Kompatibilita** (nutno zkontrolovat vždy): patice CPU ↔ socket základní desky, generace RAM (DDR4/DDR5) podporovaná deskou, rozměr GPU vs case, výkon a konektory PSU vs GPU/CPU.

## Instalace OS a ovladačů – postup
1. Vytvořit instalační médium (USB) s OS.
2. Nastavit v BIOSu boot prioritu na USB.
3. Instalace OS, poté instalace **chipset driverů** (základní deska) jako první.
4. Instalace GPU driverů, poté ostatních periferií.
5. Aktualizace přes Windows Update / distribuční repozitáře.

## BIOS – co zmínit
- zapnutí **XMP/EXPO profilu** pro jmenovitou frekvenci RAM (jinak běží na nižší defaultní),
- boot pořadí, Secure Boot + TPM (nutné pro Windows 11),
- fan curve / teplotní limity pro tišší/chladnější provoz.
