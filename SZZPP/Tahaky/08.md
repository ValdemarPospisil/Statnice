# Otázka 8: Bash skript – hledání obrázků, CSV výstup

Hotový, funkční skript (uprav si název/parametry dle konkrétního zadání):

```bash
#!/bin/bash
# Použití: ./hledej.sh <adresar> <vystupni_soubor.csv> <pripona1> [pripona2 ...]

# 3) kontrola parametrů
if [ "$#" -lt 3 ]; then
    echo "Použití: $0 <adresar> <vystup.csv> <pripona1> [pripona2 ...]" >&2
    exit 1
fi

dir="$1"
output="$2"
shift 2
extensions=("$@")

if [ ! -d "$dir" ]; then
    echo "Chyba: adresář '$dir' neexistuje." >&2
    exit 1
fi

# sestavení podmínky pro find: -iname "*.ext1" -o -iname "*.ext2" ...
find_args=()
for ext in "${extensions[@]}"; do
    find_args+=(-iname "*.${ext}" -o)
done
unset 'find_args[${#find_args[@]}-1]'   # odstranit poslední nadbytečné -o

echo "cesta,velikost_B" > "$output"

total_count=0
total_size=0

while IFS= read -r -d '' file; do
    size=$(stat -c%s "$file")
    echo "\"$file\",$size" >> "$output"
    total_count=$((total_count + 1))
    total_size=$((total_size + size))
done < <(find "$dir" -type f \( "${find_args[@]}" \) -print0)

# 1) setřídění podle velikosti (vzestupně), hlavička zůstává na místě
{ head -n 1 "$output"; tail -n +2 "$output" | sort -t',' -k2 -n; } > "${output}.tmp"
mv "${output}.tmp" "$output"

# 2) konzolová statistika
echo "Nalezeno souborů: $total_count"
echo "Celková velikost: $total_size B"
```

## Poznámky k úpravě pro jinou úlohu
- `find -iname` → case-insensitive; pokud chceš case-sensitive, použij `-name`.
- `stat -c%s` je pro Linux (GNU coreutils); pokud by šlo o macOS/BSD, bylo by `stat -f%z`.
- `-print0` + `read -d ''` = bezpečné i pro názvy souborů s mezerami.
- Rozšíření o další statistiky = přidat další proměnné a `echo` na konci.
- Kontrola parametrů se dá rozšířit o ověření, že přípony jsou neprázdné, případně že soubor `$output` lze zapsat.
